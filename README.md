# rfsync

**rfsync**는 데스크톱과 원격 서버 간 실시간 양방향 파일 동기화를 지원하는 오픈소스 애플리케이션입니다.

## 소개

여러 환경에서 파일을 간편하고 안정적으로 동기화하는 것을 목표로 합니다.

특정 외부 서비스에 의존하지 않고 사용자가 직접 파일 동기화 환경을 구성하고 관리할 수 있도록 합니다.

## 주요 기능

- 실시간 파일 동기화
- 양방향 파일 동기화
- 파일 변경 사항 감지
- 데스크톱과 원격 서버 간 동기화
- 셀프 호스팅 환경 지원
- 특정 외부 서비스에 종속되지 않는 독립적인 운영
